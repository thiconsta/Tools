# Cybersecurity Tools

Repositório pessoal de ferramentas, referências e comandos úteis para estudos de cibersegurança, laboratórios e CTFs.

> [!IMPORTANT]
> Todo o conteúdo deste repositório deve ser utilizado somente em ambientes próprios ou com autorização explícita.

## Categorias

| Categoria | Conteúdo |
| --- | --- |
| [Hashes](hashes/README.md) | Identificação, consulta, extração, recuperação de senhas e verificação de integridade |

## Sobre o projeto

Os guias incluem:

- explicação da finalidade de cada ferramenta;
- exemplos de instalação e uso;
- comandos úteis para laboratórios;
- limitações e cuidados de segurança;
- links para a documentação oficial.

Novas categorias serão adicionadas conforme o avanço dos estudos.

## Uso ético

Este repositório possui finalidade exclusivamente educacional. Não utilize as ferramentas ou técnicas documentadas contra sistemas, contas ou dados sem autorização.
